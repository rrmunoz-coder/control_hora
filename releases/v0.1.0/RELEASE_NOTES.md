# Release notes v0.1.0

## Resumen ejecutivo

Primera base limpia versionada de ATLAS para pruebas integrales. La versión consolida el sistema operativo del equipo: registro de trabajo, administración de estructura, proyectos/servicios, tareas, validaciones y base de análisis financiero-operacional.

## Beneficio

ATLAS transforma el registro semanal en información ejecutiva para gestionar capacidad, controlar esfuerzo, analizar costos y justificar automatizaciones con impacto económico.

## Validaciones clave

- Código Python compilable.
- Paquete generado sin `.venv`.
- Paquete generado sin `config.ini` real.
- Sin cachés Python.
- Sin paquetes históricos.
- Sin columna física `ES_TAREA_PROYECTO`.
- Compatibilidad V3 para imputación directa a proyectos.
