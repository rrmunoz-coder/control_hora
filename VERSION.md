# Versión vigente

- **Versión:** S.2.0
- **Fecha:** 2026-08-07
- **Nombre:** Snapshot estable de producción LDAP
- **Estado:** Versión consolidada e instalable basada en el runtime validado
- **Baseline funcional:** ATLAS v0.3.0

S.2.0 consolida el código que está operando, las migraciones v0.3.0, la imputación directa a proyectos V3 que faltaba en la raíz del repositorio, el servicio Windows `ATLAS_Web`, las pruebas y la compatibilidad LDAPS temporal `DEFAULT:@SECLEVEL=1` necesaria en la infraestructura validada.

La etiqueta `S.2.0` se conserva como identificador de release solicitado. No elimina la historia SemVer previa (`v0.1.0`, `v0.2.0`, `v0.3.0`).
