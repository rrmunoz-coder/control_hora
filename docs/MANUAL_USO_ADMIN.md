# Manual simple de uso y administración

## Objetivo operacional

ATLAS permite registrar y gobernar el trabajo semanal del equipo, manteniendo trazabilidad sobre qué se hace, quién lo ejecuta, cuánto esfuerzo consume y qué oportunidades existen para optimizar o automatizar.

## Uso usuario final

1. Ingresar a ATLAS.
2. Abrir la planilla semanal.
3. Seleccionar proyecto o tarea.
4. Registrar horas enteras por día.
5. Indicar modalidad: presencial, remoto, licencia, vacaciones, progresivo, permiso, compensatorio o descanso.
6. Guardar la semana.

## Uso administrador

El administrador gestiona:

- Usuarios.
- Roles y permisos.
- Unidades organizacionales.
- Proyectos y servicios.
- Tareas.
- Modalidades.
- Parámetros de costos y score.

## Reglas principales

- Las horas reales las registra cada usuario.
- La estructura de proyectos, servicios y tareas la administra ATLAS.
- Los proyectos se pueden imputar directamente mediante tarea técnica interna.
- Las unidades se desactivan; no se eliminan físicamente si tienen historial.
- Los costos por persona no se cargan manualmente en la imputación; se calculan desde categoría, tarifa y horas.
